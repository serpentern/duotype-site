# DuoType public website

DuoTypeの紹介・サポート・プライバシーポリシーを公開する静的サイトです。

- 紹介: https://serpentern.github.io/duotype-site/
- サポート: https://serpentern.github.io/duotype-site/#support
- プライバシー: https://serpentern.github.io/duotype-site/privacy.html

GitHub Pagesはmainブランチのルートを配信します。ビルドや外部JavaScriptは不要です。
HTML・CSS・assetsを更新してmainへpushすると反映されます。
アプリのソースコードはこのリポジトリには含めません。

ローカル確認: `python3 -m http.server 8788` を実行し http://localhost:8788/ を開いてください。
